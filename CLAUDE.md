# 悪知恵 (Warujie) — working notes for Claude

**What this is:** the handover for anyone (human or Claude) working on this repository. Claude Code
reads this file automatically. It is public (the repository is public), so it holds no private
details: those live in the owner's private notes.

**The site:** warujie.jp, a free Japanese Magic: The Gathering card search. It lets people:
- search Japanese and English names and rules text, by role ("removal", 「除去」), with filters;
- open card pages showing every printing and language, prices (US/EU, yen conversion), shop
  listings, price history and shop links;
- browse sets;
- see a metagame tab (deck shares, win rates, trends) and deck pages with sample lists and
  MTG Arena/MTGO export;
- see price movers and Commander combos (on the preview page);
- install it as an app.

It has no sign-up, cookies, analytics or ads. The footer promises that, so keep it true.

## Rules (the owner's, keep them)

1. **Staging first.** Work goes to the `staging` branch, which builds the test site
   `https://staging-warujie.warujie-mtg.workers.dev` (noindex). `main` is the live site.
2. **Publish only when the owner says "publish".** Before publishing, save the live `main` as a
   branch `backup-<YYYY-MM-DD>-before-<what>`, then merge `staging` into `main` (`--no-ff`, a
   "Publish …" message listing what goes live), push, and confirm the Workers build.
   Tags and branch deletes are refused from Claude's sessions, so backups are branches.
3. **Other sites' data:** shops that forbid reuse (Hareruya, BIG MAGIC, magi, Yuyu-tei…) get
   **links only**. For anything that needs permission (shop prices, Wizards' Gatherer, MTG Wiki,
   Wisdom Guild…), **ask the owner first; never scrape without permission**. Scryfall,
   MTGJSON, TCGCSV, Cardmarket's price guide, Card Kingdom's and Mana Pool's public price lists,
   CardTrader's API (with a token) and Commander Spellbook are the permitted sources in use.
4. **Scryfall etiquette:** at least 100 ms between API requests (the site queues them:
   `scryfallTurn()`), a real User-Agent from scripts, and the bulk files for anything big.
5. **No secrets in the repo or in chat.**
   - The CardTrader API token is the GitHub secret `CARDTRADER_TOKEN` in warujie-prices.
   - Never ask the owner to paste a token (Cloudflare, GitHub…) into chat.
   - The site's contact address is assembled in JavaScript so it never appears in the page
     source; keep it that way.
6. **Ads:** none for now. They're planned for later, and the Fan Content Policy allows them. When
   they come, the footer's privacy promise and the Wizards permission request must be revisited.
7. Habits that worked well with the owner: show a preview or screenshots of visual changes,
   offer 2–3 options for layout ideas, explain in plain words, and keep backups before anything
   goes live.

### Files in this repo

- **`index.html`:** the whole site in one file, about 9,000 lines of HTML, CSS and JS. Sections are
  marked `// ---- name ----`: database, search parsing, Japanese text, legality, pictures,
  prices, language buttons, sets, routing, filters, recent searches, metagame, price history,
  combos, suggestions, install, home, decks, export. Interface strings are in `STR`, each with a
  Japanese and an English entry (`t(key)`).
- **`preview.html`:** generated by `python3 tools/make_preview.py`; never edit it by hand. It's the
  same page with `noindex` and `data-combos="1"` (combo suggestions on).
- **`worker.js`** runs only for `/`, `/index.html`, `/preview*` and `/ja_cards.json`:
  - it gzips HTML itself and marks it `no-transform`, so Cloudflare doesn't inject its analytics
    or bot scripts;
  - it serves the card database brotli-compressed (`ja_cards.json.br`, made at deploy by
    `tools/brotli_db.mjs`);
  - for link-preview bots it rewrites the og/title tags of card, deck, set, meta and price pages.
- **`ja_cards.json.gz`** is the card database and **`printings.json.gz`** its printings (below).
- **`meta.json`, `meta_decks.json`, `meta_lists/`** hold the metagame data, rebuilt daily by
  `.github/workflows/update-meta.yml` (`build_meta.py`). That job commits to `main` at 18:40 UTC.
- **`combo_ja.js`** has the Japanese wording for combo results.
- **`manifest.webmanifest`, `sw.js`, `icons/`, `og.png`** make it installable, give it a
  network-first offline copy (cache `warujie-v2`) and provide the share picture.
  `tools/make_icons.py` centres the icons by ink.
- **`.assetsignore`** lists what is *not* served: `tools/`, `dev/`, `docs/`, `CLAUDE.md`,
  workflows, scripts. Anything new that shouldn't be public goes there.
- **`dev/`** holds the test suites (see `dev/README.md`). **`tools/`** holds the scripts below.
  **`docs/`** is the developer guide (not published on the site).

## The card database (`ja_cards.json.gz`)

One row per card (about 33,800), with these fields: `id` (the Scryfall printing shown in
results, a Japanese one where possible), `oracle_id`, `name_en`, `name_ja`, `type_en`, `type_ja`,
`oracle_en`, `oracle_ja`, `mana_cost`, `colors`, `cmc`, `power`, `toughness`, `rarity`, `set`,
`keywords`, `released_at` (first release), `alt_names_ja` (older Japanese names, `|`-separated),
`legal` (letters s p m l v a c), `layout` (the card's shape from Scryfall when not an ordinary
one-faced card: split, transform, modal_dfc, adventure…; searched by 分割カード, 両面カード),
`name_kana` (the reading: the あいうえお sort, and names typed in hiragana; never shown),
`rarities` (every rarity the card was printed at, `c u r m s b`, for the rarity filters), `sets`
(every set it was printed in, oldest first, for `e:`) and `treatments` (`b s x f o u t e n`:
borderless, showcase, extended art, full art, old frame, future frame, textless, etched,
serialized; upper case where a Japanese printing has it).

- **Built by `tools/build_ja_database.py`** (2.4) from Scryfall's `all_cards` bulk file, together
  with **`printings.json.gz`** (every printing's languages, rarity and treatments, about 0.3 MB,
  for the card page's language buttons). Scryfall serves bulk files as gzipped JSON Lines
  (`jsonl_download_uri`) since September 2026; the builder and `warujie-prices` handle that.
- **Rebuilt every Monday 02:30 UTC** by `.github/workflows/update-cards.yml`
  (`tools/update_database.py`: build, name fixes, readings, then `tools/check_database.py`,
  which refuses a build that lost cards, Japanese names or texts, printings or rarity counts).
  It commits to `staging` only when cards changed, with a what's-new note; it goes live with the
  next publish. The schedule runs from `main` (it starts after the first publish that carries
  it); "Run workflow" starts it by hand. Its push doesn't start the Name readings workflow, so it
  runs both name tools itself.
- **Whenever the database changes on `main` or `staging`** (or `tools/name_fixes_ja.json`,
  `tools/fix_names.py` or `tools/name_readings.py` changes there),
  `.github/workflows/name-readings.yml` runs and commits back to that branch, so pull before your
  next commit. It runs:
  - `tools/fix_names.py`, which applies `tools/name_fixes_ja.json` (280 Japanese names Scryfall
    has wrong or missing, read off the real Japanese cards);
  - `tools/name_readings.py`, which writes `name_kana` with SudachiDict, preferring printed
    furigana.
- **The one-off improvements once made by hand are built in since 2.4:** `type_ja` from another
  Japanese printing when the chosen one has none (888 cards), and a Japanese printing with a real
  scan at the same rarity in a regular set (`CardEntry.picture()`). `tools/audits/db_updates.py`
  is no longer needed after a rebuild. The first full 2.4 rebuild (2026-10-16) changed 933
  pictures, all by rules already in 2.3: mostly a regular frame over a borderless/etched variant
  in the same set.
- **Scryfall data facts learned the hard way:**
  - Some old sets file their non-English printings under another set code with the same
    numbers: `4bb`↔`4ed`, `bchr`↔`chr`, `fbb`↔`3ed`. The language buttons pair these
    (`SET_TWIN`).
  - Japanese two-part cards often carry the English name on a face, or none at all. Fixed by the
    name list.
  - About 4,800 English printings in sets that were printed in Japanese have no Japanese entry
    in Scryfall (e.g. Dominaria Remastered's split cards #207–216). About 4,000 cards have a
    Japanese name but no Japanese text anywhere in Scryfall. Nothing to show for these until
    another source is permitted.
  - Some Omen printings repeat the front name (`Bloomvine Regent // Claim Territory // Bloomvine
    Regent`); the builder drops the repeat (`english_name()`).
  - Many old Japanese printings have only a placeholder image. The page then shows the same
    printing's English picture with a note naming the language.
  - Scryfall's `r:mythic` counts a card once for every rarity any of its printings has
    (Sengir Vampire: uncommon, rare, mythic). The `rarities` field does the same. Checked
    2026-10-16: the site matches Scryfall's paper counts within a handful. Scryfall's plain
    counts are higher by Arena/MTGO-only cards (left out on purpose), and Scryfall hides about
    825 playtest, joke-promo and withdrawn cards the site keeps (docs/data.md has the detail).
  - Italian Legends/The Dark printings sometimes carry a rarity their English printing
    doesn't. The builder used to keep such a printing as the card's picture when the English
    one ranked level (116 cards showed an Italian picture, 10 a wrong rarity); fixed in 2.3.

## How the card page picks printings and languages

- Language buttons (JP EN CS CT FR DE…) appear under the picture, one per language the **exact
  printing** exists in. They come from `printings.json.gz` (loaded once per visit); pressing a
  button fetches that one printing (`openPrinting()`). A printing the file doesn't have yet falls
  back to one Scryfall search, `e:<set> cn:"<number>" include_multilingual=true` (plus the twin
  set code where one exists).
- There is never a jump to another set's printing. A printing that exists only in English shows
  EN alone.
- The `?print=<lang>` URL parameter shows that printing's own language; otherwise the site
  language decides.
- Prices for a non-English printing come from the English printing with the same set and
  number. Price history is kept for English printings.

## Search, in brief

- Results come from the local database, searched in the browser. Scryfall's live API is the
  fallback if the database can't load.
- **Default order:** best matches first, then A→Z, with Japanese names ordered by reading
  (`name_kana`). Readings are never displayed.
- **Name matching ignores punctuation:** `nameKey()` drops punctuation and spaces (and folds
  kana), so "yawgmoth thran" finds "Yawgmoth, Thran Physician".
- **Players' words count:** slang and everyday wording are read as the cards' own wording
  as well (`JA_SLANG`, `JA_KW_SLANG`, `EN_WORD_ALIAS`, `WORD_FILTERS`): 山札 → ライブラリー,
  3ダメージ → 3点のダメージ, 2ドロー, サクる, 自分のクリーチャー, 攻撃したとき → 攻撃するたび,
  フライヤー/飛行持ち → 飛行, PW, 置物, unblockable, sac. `・`, 全て/すべて and 時/とき are
  ignored. 墓地から手札 matches the two words in one ability, in that order first. A note
  above the results says what a word was read as. Words that are slang only sometimes
  (カウンター, ロード, ラス, ティム) stay text and the note offers the role
  (`AMBIG_ROLE_WORDS`); with a color or mana value (青のカウンター) they are the role, and ロード
  with a creature type too (エルフ ロード). Slang works inside a sentence (ETBでカードを引く,
  死亡時にカードを引く), and words the cards say differently are read their way: シャッフル →
  切り直す, ディスカード → 捨てる, ミル → 切削, パートナー → 共闘, トランプル付与 → トランプルを得る,
  1マナ安く → {1}少なく, 奪う → コントロールを得る.
- **Hiragana game words** (typed before converting, on phones) are read as kanji/katakana
  (`JA_READINGS`, longest word first): はかい → 破壊, くりーちゃーをはかい, じょきょ (the role).
  Names in hiragana still match by kana folding.
- **Typed the way players type:** punctuation (、。「」) is ignored, so a sentence typed without it
  matches; `{T}:` and `-2:` in typed text are text, not filters; a card's own name in older
  Japanese text reads as このクリーチャー / この土地 (`rowJaText()`); English names match without
  hyphens or accents ("wrenchrigger", "lim dul").
- **Colors and mana values narrow:** 白 天使, 白の天使, 3マナ ゴブリン, 黒のクリーチャー, red goblin
  filter by color / mana value (`narrowingWord()`), except inside a card name (黒 騎士, black
  lotus) or in quotes. A note says so.
- **Card shapes:** 分割カード, 両面カード/両面/DFC, MDFC, 変身カード, 反転カード, 合体カード,
  出来事カード, 前兆カード, split card, double-faced card, and `is:split`/`is:dfc`/`is:mdfc`
  (`CARD_SHAPES`, from the `layout` field).
- **Names as players type them:** a name in hiragana matches by its reading (いなずま → 稲妻,
  `yomiQuery()`); nicknames and the katakana of English-only cards (ボルト, ブレスト, JTMS,
  ブラックロータス, アンダーグラウンドシー) show the card first (`CARD_NICKNAMES`); a Japanese name
  typed slightly wrong that finds nothing is searched as the closest name, with a note
  (渦巻く知識 → 渦まく知識, ジェース → ジェイス: `closestJaName()`).
- **More narrowing words:** guilds/shards/wedges (ボロス 除去), formats (モダン 除去), rarities
  (神話レア ドラゴン), パワー3以上; a card type beside them is the type (白 クリーチャー). Land
  nicknames are roles (ペインランド, チェックランド, ファストランド, スローランド, ミシュラランド,
  トライランド, パスウェイ).
- **Cards with no Japanese text** (about 4,000) are reached by Japanese phrases through
  `JA_WORD_EN`: 墓地から手札 finds an English line with graveyard and hand. They come after
  the Japanese matches in the same group.
- **Rarity** (the C U R M buttons, several at once, `r:m`, 神話レア ドラゴン) finds a card by any
  rarity it was printed at, as Scryfall does; a tile whose shown printing is another rarity still
  says the rarity asked for (神話レア), with a ↓/↑ arrow beside it (owner's choice over 神話レア版あり).
- **Printings:** `e:mh3` / セット:モダンホライゾン3 finds every card printed in the set, reprints
  too (`sets`); ボーダーレス, ショーケース, 旧枠, 拡張アート, フルアート, シリアルナンバー, `is:showcase`
  find cards with such a printing (`TREATMENTS`), and beside 日本語版 or `lang:ja` a Japanese one
  (日本語版 ボーダーレス); 日本語版 alone finds cards printed in Japanese.
- **Also in place:**
  - spelling correction against words that exist on cards;
  - role words via the tag file from warujie-prices (`t/`);
  - recent searches, kept in the browser only;
  - English mode;
  - lightweight mode (軽量).

## How to work on it

1. **Set up git.** Clone, check out `staging`, and make sure it tracks the remote (Claude's
   sandbox sometimes fetches only `main`):
   `git config --add remote.origin.fetch '+refs/heads/staging:refs/remotes/origin/staging'`.
   The remote moved to `https://github.com/warujie/Warujie.git`.
2. **Edit** `index.html` (and the other files), then run `python3 tools/make_preview.py`.
   Update the matching doc in `docs/` (see "Documentation" above).
3. **Test** with `python3 dev/tests/e2e.py` (about 860 offline checks; needs a warujie-prices
   clone next to this repo) and `cd dev/searchbench && python3 search_checks.py ../../index.html`
   (about 240 real-data search checks, including the 100 common Japanese searches and the
   everyday words in `dev/searchbench/common_searches.py`), and `python3 dev/check_docs.py` (the docs still match the code).
   Add checks for every new feature or fix. Look at it too:
   screenshot desktop (1280px) and phone (390px) with Playwright.
4. **Commit to `staging`** with a message that says what changed for users, then push.
5. **Confirm the build:**
   `gh api repos/warujie/Warujie/commits/<sha>/check-runs` (or the GitHub MCP tools where `gh`
   isn't available) should show "Workers Builds: warujie" as success. If a push didn't start a
   build, an empty commit retriggers it.
6. **Tell the owner** what's on the test site, and **publish only on "publish"** (rule 2).
7. **Rolling back:** Cloudflare dashboard → Workers & Pages → warujie → Deployments → Rollback
   (fast). Or reset `main` to the backup branch and push. `README.md` explains both for the owner.

## Reaching other websites from Claude's sandbox

Claude's sandbox can't reach most of the web: Scryfall's API, warujie.jp itself and shop sites
are blocked. GitHub, package registries and the web-search/fetch tools work.

To fetch or process outside data (Scryfall bulk files, card images, a site's terms page), use a
throwaway branch with a workflow that runs on push, does the fetch on GitHub's runners and
commits the results back. The branch `probe-shops` was used for this;
`tools/audits/probe-workflow.example.yml` is the template.

- Run steps inside `( … ) > log 2>&1 || true` so a failure still commits the log.
- Use `actions/setup-python` before `pip install`.
- Only fetch what the owner has allowed (rule 3).

`tools/audits/` holds the scripts written this way:

| Script | What it checks or makes |
|---|---|
| `audit_printings.py` | printings split over set codes; missing Japanese face names |
| `audit_text.py`, `db_updates.py` | Japanese type, text and picture gaps, and the fixes |
| `missing_ja.py`, `set_langs.py` | languages each set has, and missing Japanese printings |
| `face_sheets.py` | crops of Japanese card name bars, to read names Scryfall lacks |
| `rarity_audit.py` | per-rarity counts against Scryfall's search, every printing's rarity, a fresh build to compare |

Note: warujie.jp shows a Cloudflare challenge to unverified bots (including GitHub runners).
Check the live site through the `*.workers.dev` address, which runs the same Worker.

## The prices repository (warujie-prices)

- **`build_prices.py`** runs daily at 12:17 UTC and publishes to GitHub Pages without committing.
  It collects:
  - TCGplayer USD and Cardmarket EUR via Scryfall;
  - MTGJSON history;
  - lowest listings from TCGCSV and Cardmarket's price guide;
  - Card Kingdom and Mana Pool offers;
  - CardTrader EU sellers (needs the secret).
- **`build_combos.py`** (Commander Spellbook) feeds the combo panel.
- **`build_tags.py`** (Scryfall Tagger) feeds role search and similar cards.
- All three are steps of the one daily workflow, `.github/workflows/update-prices.yml` (it also
  runs when a builder or the workflow changes on `main`). Combos and tags are rebuilt weekly and
  copied over from the published data on the other days.
- The site reads it all from `https://warujie.github.io/warujie-prices/`. The exchange rate comes
  from frankfurter.dev (ECB).
- The **JP market tab** shows "準備中" (in preparation) plus shop links until shops grant
  permission. Japanese shop prices are added only for shops that said yes.

## Decisions already made (don't undo without asking)

- **JP price tab:** the "B+D" design. On phones, a "load more" button; the US/EU listings sit in a
  thin-scrollbar box.
- **Language buttons:** same-size buttons under the picture, only for languages the exact
  printing has (see above).
- **Two-part card names** read in their own language on both halves (e.g. 呪文嘲りの集会 // お返し).
- **Star City Games:** link only; there's no price feed.
- **Colour editions** (Selesnya/Golgari test pages) are retired. `EDITIONS` keeps only `main`.
- **Saved browser settings** keep their old `akuchie-` names (theme, language, view, market…).
  Renaming them would reset every visitor's saved choices, so leave them.
